# 🥗 ผักสดใส (Clean & Healthy)

เว็บไซต์สำหรับร้านอาหารคลีนที่นำเสนอเมนูเพื่อสุขภาพ บทความที่มีประโยชน์ และช่องทางการติดต่อ ด้วยดีไซน์ที่ทันสมัยเน้นความสวยงาม ใช้งานง่าย และรองรับการแสดงผลบนทุกหน้าจอ (Responsive Web Design)

## ✨ คุณสมบัติเด่น (Features)

- **ดีไซน์ล้ำสมัย (Glassmorphism & 3D)**: หน้าเว็บได้รับการออกแบบด้วยเอฟเฟกต์ Glassmorphism แบบกระจกใส 3 มิติ และแอนิเมชันกราฟิกลอยตัวอย่างเป็นธรรมชาติ
- **รองรับทุกอุปกรณ์ (Responsive Design)**: โครงสร้างเลย์เอาต์ถูกปรับให้แสดงผลได้อย่างสมบูรณ์แบบ ทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- **ระบบเมนูบนมือถือ (Mobile Navigation)**: มีระบบเมนูแบบสไลด์ลง (Dropdown) สำหรับมือถือที่ใช้งานง่าย
- **ประสิทธิภาพสูง**: โหลดเร็วและไม่ต้องพึ่งพาเซิร์ฟเวอร์แบบซับซ้อน (Static Website)

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

- **โครงสร้างหลัก**: HTML5
- **การตกแต่งสไตล์**: Tailwind CSS (ผ่าน CDN) ช่วยให้จัดการสไตล์ได้อย่างรวดเร็วและเป็นระบบ
- **แบบอักษร**: Google Fonts (Kanit) เพื่อให้อ่านภาษาไทยได้ชัดเจนและสวยงาม
- **ไอคอน**: Font Awesome 6
- **สคริปต์ (การเคลื่อนไหว/เมนู)**: Vanilla JavaScript

## 📂 โครงสร้างเว็บไซต์ (Pages)

1. `index.html` - **หน้าแรก**: นำเสนอจุดเด่นของร้านอาหารคลีน และเชื่อมโยงไปยังส่วนต่างๆ
2. `menu.html` - **เมนูอาหาร**: แสดงรายการอาหารคาว อาหารหวาน และเครื่องดื่ม พร้อมรูปภาพและราคา
3. `article.html` - **บทความสุขภาพ**: แหล่งรวบรวมเคล็ดลับการดูแลสุขภาพและการเลือกทานอาหาร
4. `about.html` - **เกี่ยวกับเรา**: บอกเล่าถึงวิสัยทัศน์ พันธกิจ และค่านิยมของแบรนด์ "Clean & Healthy"
5. `contact.html` - **ติดต่อเรา**: ช่องทางการติดต่อ รวมถึงฟอร์มส่งข้อความและแผนที่ Google Maps แบบฝัง

## 🚀 วิธีการติดตั้งและรันเว็บไซต์

เนื่องจากเป็นเว็บไซต์ประเภท Static HTML จึงสามารถเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งเครื่องมือใดๆ เพิ่มเติม

**วิธีที่ 1: เปิดโดยตรงบนเบราว์เซอร์**
1. ดาวน์โหลดหรือ Clone โฟลเดอร์ `final pai` มาไว้ในเครื่อง
2. ดับเบิลคลิกที่ไฟล์ `index.html` หรือลากไฟล์ไปวางในเว็บเบราว์เซอร์ (Google Chrome, Safari, Edge ฯลฯ) เพื่อเริ่มต้นใช้งาน

**วิธีที่ 2: รันผ่าน Local Server (แนะนำสำหรับการพัฒนา)**
หากคุณใช้งานโปรแกรมแก้ไขโค้ดอย่าง VS Code สามารถติดตั้ง Extension **Live Server**
1. คลิกขวาที่ไฟล์ `index.html`
2. เลือก "Open with Live Server"
